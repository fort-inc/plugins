# review — 別の目で見直す

**合言葉 = 「見直して」。** 出す前の成果物(文章・資料・画面・決めごと)を、作った目とは別の目で一周する。

## 進め方

1. **対象の実物を開く。** 話に出た説明ではなく、ファイル・画面・文面そのものを読む。実物を見ずに見直しを始めない。
2. **約束との一致を先に確かめる。** その成果物は何のために作ったか(誰に何を約束したか)を1文で置き、その約束を満たしているかを最初に判定する。細部の指摘はその後。
3. **受け取る人として一周する。** 作った目線を捨てて、受け取る人(お客・読み手・使う人)としてはじめから通して歩く。途中で詰まる場所・意味が取れない場所を拾う。
4. **指摘は 1, 2, 3 の通し番号で、1件ずつ直せる大きさに割って出す。** 大きい指摘から並べる。直し方の案があれば1行で添える。

## 出す形

- 最初に結論を1行(このまま出せる / 直してから出す)。
- 指摘は番号付きの一覧。各件 = 何が・どこで・どう直すか。
- 良かった点を最後に1〜2件(直す点だけ並べない)。

## やらないこと

- 実物を確かめずに「問題ありません」と言わない。
- 指摘と一緒に自分で直し始めない(直すかどうかは頼んだ人が決める)。
- 好みの言い換えを指摘に混ぜない(約束と受け取りやすさに関わるものだけ)。
